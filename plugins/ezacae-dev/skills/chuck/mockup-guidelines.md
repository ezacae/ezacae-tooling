# Directives maquettes HTML

Interfaces distinctives, qualite production, pas de "AI slop".

## Direction esthetique

Avant de coder, s'engager sur :

- **Objectif** : Quel probleme cette interface resout-elle ? Qui l'utilise ?
- **Ton** : Direction conceptuelle claire — medical/bien-etre raffine, doux/pastel, editorial/magazine, luxe/minimal, etc.
- **Differenciation** : Qu'est-ce qui rend cette interface memorable ?

## Typographie

Polices distinctives et caracterielles (Google Fonts). Associer une police display avec une police body raffinee. Eviter Arial, Inter, Roboto, polices systeme.

## Couleur & Theme

Variables CSS pour la coherence. S'appuyer sur la palette bleu ciel de l'app (`#0369a1`, `#e0f2fe`, `#f0f9ff`). Couleurs dominantes avec accents marques.

## Motion & Micro-interactions

Animations CSS pour les effets (transitions, hover states, reveals decales via `animation-delay`). Focus sur les moments a fort impact.

## Composition spatiale

Layouts inattendus. Asymetrie. Superposition. Espace negatif genereux OU densite controlee.

## Fonds & Details visuels

Creer de l'atmosphere et de la profondeur. Gradient meshes, textures noise, motifs geometriques, transparences superposees.
